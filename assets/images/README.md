## Image Specifications

### Size Guidelines:
- **App Icons**: 192x192px, 512x512px
- **Splash Screen**: 512x512px
- **Onboarding**: 800x600px
- **Feature Illustrations**: 400x600px
- **Empty States**: 300x300px
- **Avatars**: 200x200px
- **Backgrounds**: 1080x1920px (portrait)

### Format Guidelines:
- **PNG**: For images with transparency, illustrations, icons
- **JPEG**: For photos, backgrounds without transparency
- **WebP**: For web-optimized images (smaller file size)

### Color Palette:
- **Primary**: #2196F3 (Blue)
- **Doctor Accent**: #9C27B0 (Purple)
- **Patient Accent**: #00BCD4 (Cyan)
- **Success**: #4CAF50 (Green)
- **Error**: #FF5252 (Red)
- **Background Light**: #F5F7FA
- **Background Dark**: #121212

### Style Guidelines:
- **Illustration Style**: Modern, flat design with subtle shadows
- **Color Usage**: Use app theme colors consistently
- **Complexity**: Keep illustrations simple and clear
- **Accessibility**: Ensure good contrast ratios
- **File Size**: Optimize for mobile (target <200KB per image)

## Export Settings

### For PNG:
- Transparency: Yes
- Compression: Medium (balance quality and size)
- Color Space: sRGB
- Resolution: 72 DPI (screen) or 144 DPI (retina)

### For JPEG:
- Quality: 85-90%
- Progressive: Yes
- Color Space: sRGB

### Optimization Tools:
- **TinyPNG** - https://tinypng.com/ (PNG compression)
- **Squoosh** - https://squoosh.app/ (Google's image optimizer)
- **ImageOptim** - https://imageoptim.com/ (Mac app)
