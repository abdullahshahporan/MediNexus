## Design Guidelines

### Style Requirements:
- **Line Weight**: 2px stroke for outlines
- **Style**: Modern, minimalist, consistent line art
- **Corners**: Rounded (border-radius: 2px on sharp corners)
- **Format**: SVG (vector format)
- **Color**: Monochrome/single color (app will apply theme colors)
- **Background**: Transparent

### Color Scheme:
- **Primary Blue**: #2196F3
- **Doctor Accent**: #9C27B0 (Purple)
- **Patient Accent**: #00BCD4 (Cyan)
- **Success Green**: #4CAF50
- **Error Red**: #FF5252
- **Warning Orange**: #FF9800
- **Info Blue**: #2196F3

### Export Settings:
- Format: SVG
- Artboard: Match icon dimensions
- Expand strokes to paths
- Remove unnecessary groups
- Optimize/minify SVG code
